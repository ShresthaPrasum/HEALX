# HEALX

## About
Healx is a health units calculating web application that offers a variety of health calculatir to the users in order to help them montior and improve their health. They can solve their health problems more efficiently.

<hr>

## Available Calculators:
- BMI Calculator
- Calorie Deficit Calculator
- Protein Calculator
- Maintenance Calorie Calculator
- Ideal Calculator and coming soon......

## Features: 
- Helps user to find their problem
- Helps user to get more information about their health
- Tells user how much food or nutrients they should consume.
- Tells user how to maintain their healthy physique.

## Technologies Used:
- HTML
- CSS
- JS
